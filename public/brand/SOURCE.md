# PumpShield identity assets

The glass P/droplet mark is an original image generated for PumpShield on 8 November 2026. It takes material inspiration from contemporary refractive app icons, without using Apple's logo or music-note trademark. `mark.webp` and the app icons are resized derivatives. `src/app/icon.svg` is an original lightweight P/droplet alternative; `truck-marker.svg` is an original top-down tanker vector.

UI icons use [Phosphor React](https://github.com/phosphor-icons/react), MIT licensed. MapLibre GL JS is BSD licensed; the exact installed worker and its license are copied locally at build time. OpenFreeMap/OpenStreetMap and terrain/provider attribution is displayed within the map. Existing reference wall and tanker illustration attribution remains in their respective asset directories.
